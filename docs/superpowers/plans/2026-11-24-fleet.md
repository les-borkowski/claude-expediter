# Fleet (background drivers, status, pause, resume) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drivers run as Claude Code background sessions; `slots.py` gains driver state, progress, `pause` and `resume`; a PreToolUse hook enforces pause; drivers pause with a WIP commit and resume from the recorded stage.

**Architecture:** Extend `tools/slots.py` (stdlib CLI) with `status --json`, `pause`, `resume`, reading `claude agents --json` for liveness. Add `hooks/pause_gate.py` (PreToolUse on `Agent`). Command markdown carries the driver-side pause/resume behaviour.

**Tech Stack:** Python 3.8+ stdlib, Claude Code plugin hooks and commands.

**Spec:** `docs/superpowers/specs/2026-11-24-fleet-panel-design.md`

## Global Constraints

- Never call `claude rm`; never kill a process the driver didn't start.
- Launch line: `claude --bg --name <slug> --model sonnet --advisor opus "/expediter:drive-tickets <slug>"`, run with the worktree as cwd; fallback the existing `wt … pwsh -NoExit -Command …` line.
- PAUSE flag path: `<worktree>/.scratch/<slug>/PAUSE`.
- Driver state from `claude agents --json` entry whose `cwd` equals the worktree path (normcase + realpath): `busy`→working, `idle`→idle, other→unknown, none→stopped. Checkpoint `blocked`→waiting on you, `paused`, `done` override.
- WIP commit message: `WIP(pause): <ticket> at <stage>`.
- Single-session use unchanged; build commands unchanged without a "resume at stage" line.
- expediter version `0.9.0`.

## Review Focus

1. `claude` not on PATH, or `claude agents --json` fails/prints non-JSON → status still prints, driver column `unknown` (`test_agents_unavailable_is_unknown`).
2. Worktree path casing/separators differ between git and `claude agents` (`C:\` vs `c:\`, `/` vs `\`) → still matched (`test_driver_match_normalises_paths`).
3. PAUSE file exists but hook input has no cwd / unreadable .scratch → hook allows (never blocks a non-expediter session by accident) (`test_gate_no_cwd_allows`).
4. `resume` with a feature already running (busy/idle) → not relaunched (`test_resume_skips_live_driver`).
5. Hook must not block a session whose cwd is the main checkout while a *worktree* feature is paused (`test_gate_scoped_to_own_cwd`).
